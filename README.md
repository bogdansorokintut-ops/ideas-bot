# ideas-bot

Telegram-бот, который принимает идеи игр текстом и складывает их в Google Таблицу:
**отдельный лист на каждую идею** + лист-сводка со ссылками. Первая строка сообщения становится
названием, остальное описанием, строки вида `метка: значение` уходят в поля. Опционально бесплатный
LLM дополняет то, что ты не написал.

```
Ты:  Злой маяк
     Ты — смотритель маяка, заманиваешь корабли на скалы и лутаешь обломки. Dredge наоборот.
     жанр: management, roguelite
     хук: корабль разбивается о скалы в свете твоего маяка
     рефы: Dredge

Бот: 🎮 Злой маяк
     Описание: Ты — смотритель маяка, заманиваешь корабли на скалы и лутаешь обломки. Dredge наоборот.
     Жанр: management, roguelite
     Хук: корабль разбивается о скалы в свете твоего маяка
     Референсы: Dredge
     Автор: @bogdan · 21.09.2026
     [✅ Записать] [❌ Отмена]
```

Метки полей (регистр не важен, полный список — `LABELS` в `parser.py`):

| Поле | Метки |
|---|---|
| Описание | `описание`, `суть`, `идея`, `концепт`, `о чём` |
| Питч | `питч`, `pitch` |
| Жанр | `жанр`, `genre`, `теги` |
| Core loop | `loop`, `луп`, `механика`, `механика-изюминка`, `геймплей` |
| Хук | `хук`, `фишка`, `почему это вирально` |
| Референсы | `рефы`, `референсы`, `похоже на` |
| Развитие | `развитие`, `дальше`, `потенциал` |

Незнакомая метка (`Игроков: 4–8`, `Платформа: PC`) не теряется — станет отдельной строкой на листе идеи.
Несколько идей в одном сообщении — разделяй пустой строкой, бот покажет карточку на каждую.
Если первая строка длиннее 60 символов — она считается описанием, а название режется из её начала.

## Таблица

**Лист идеи** — создаётся на каждую идею, называется как идея (дубликаты получают « (2)»).
Сверху карточка, ниже — свободное место: заметки, задачи, ссылки, скриншоты, что угодно.

| | |
|---|---|

| **Питч** | |
| **Жанр** | management, roguelite |
| **Core loop** | |

| **Развитие** | |

Строки после «Статус» — незнакомые метки из сообщения, если были.
Пустые поля бот оставляет пустыми — заполняйте руками, когда додумаете.

**Сводка** — первый лист таблицы (бот запоминает его по id, можно переименовать).
При первом запуске бот сам создаёт шапку, закрепляет её и включает перенос текста.

| Дата | Автор | Название | Питч | Жанр | Статус |
|---|---|---|---|---|---|
| 2026-09-21 | @bogdan | [Злой маяк](#) | | management, roguelite | идея |

Название — ссылка на лист идеи. Питч, жанр и статус — **формулы на ячейки листа идеи**, а не копии:
поменял статус на листе → в сводке обновилось. Правь на листе, сводку не трогай.
Колонки справа можно добавлять руками (оценки, голоса) — бот их не трогает.

## Настройка (один раз)

### 1. Telegram-бот
1. Напиши @BotFather → `/newbot` → получи токен.
2. Если бот будет в группе с другом: добавь его в группу, идеи кидайте через `/idea текст`.
   В личке команда не нужна — любое сообщение считается идеей.

### 2. Google Таблица + service account
1. Создай пустую Google Таблицу. Из URL возьми ID:
   `https://docs.google.com/spreadsheets/d/`**`<ЭТО_ID>`**`/edit`
2. https://console.cloud.google.com → создай проект (любое имя).
3. **APIs & Services → Library** → найди **Google Sheets API** → Enable.
4. **APIs & Services → Credentials → Create credentials → Service account** → имя любое → Done.
5. Открой созданный service account → вкладка **Keys → Add key → JSON** → скачается файл.
   Положи его в эту папку как `credentials.json`.
6. Скопируй email сервис-аккаунта (`...@...iam.gserviceaccount.com`) и **расшарь на него таблицу как Editor**
   (кнопка Share). Без этого бот получит 403.

### 3. LLM (необязательно)
Любой OpenAI-совместимый провайдер — три переменные в `.env`. LLM заполняет только **пустые** поля
(питч, жанр, loop, хук, рефы, развитие); что ты написал явно через метки — не трогает; исходный текст всегда
остаётся в «Описании». Если LLM упал или не ответил — строка уходит без него.

| Провайдер | `LLM_BASE_URL` | `LLM_MODEL` | Ключ | Бесплатно |
|---|---|---|---|---|
| **Groq** (рекомендую) | `https://api.groq.com/openai/v1` | `llama-3.3-70b-versatile` | https://console.groq.com/keys | ~1000 запр/день, 30/мин, без карты |
| **Gemini** | `https://generativelanguage.googleapis.com/v1beta/openai/` | `gemini-3.5-flash-lite` (актуальное имя — на ai.google.dev/gemini-api/docs/models) | https://aistudio.google.com/apikey | Flash-Lite ~500 запр/день; лимит на проект |
| **Ollama** (локально) | `http://localhost:11434/v1` | `qwen3:8b` (или любая, что тянет мак) | не нужен | без лимитов, приватно; бот должен работать на той же машине |
| **OpenRouter** | `https://openrouter.ai/api/v1` | любая модель с суффиксом `:free` | https://openrouter.ai/keys | лимиты плавают |

Имей в виду: на бесплатных тарифах Gemini (и, возможно, других облачных) запросы могут использоваться
для обучения. Если идеи хочется держать при себе — Ollama.

### 4. Кто может писать
`ALLOWED_USERS` — юзернеймы (без @) и/или числовые id через запятую. Пусто = кто угодно,
кто найдёт бота, сможет писать в вашу таблицу.

## Запуск

```bash
cp .env.example .env      # и заполни
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## Хостинг (Bothost.ru, тариф Active)

1. bothost.ru → создать бота → указать Git URL этого репозитория, ветка `main`.
2. Переменные окружения в панели (или «Загрузить из файла .env» — локальный `deploy.env`, он в .gitignore):
   - `BOT_TOKEN`
   - `GOOGLE_SHEET_ID`
   - `GOOGLE_CREDENTIALS_JSON` — содержимое `credentials.json` в base64 (или сырой JSON одной строкой)
   - `ALLOWED_USERS`
   - `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` — если нужен LLM
3. Точка входа — `bot.py`. Зависимости ставятся из `requirements.txt` автоматически.
4. Остановить локальную копию — два экземпляра одного бота конфликтуют (`TelegramConflictError`).

Обновление: `git push` в `main` — Bothost пересобирает и перезапускает бота сам.

Собрать `deploy.env` заново (например, после смены ключа):
```bash
python3 -c "import base64;print('GOOGLE_CREDENTIALS_JSON='+base64.b64encode(open('credentials.json','rb').read()).decode())"
```

## Команды
| Команда | Что делает |
|---|---|
| текст (в личке) / `/idea текст` (в группе) | разобрать идею, показать превью, спросить подтверждение |
| `/list` | список идей со ссылками на их листы |
| `/sheet` | ссылка на таблицу |

## Структура
- `bot.py` — хендлеры aiogram, кнопки подтверждения
- `parser.py` — текст → список `Idea` по правилам; метки полей в `LABELS`
- `llm.py` — дополнение пустых полей через OpenAI-совместимый API; промпт в `SYSTEM`
- `models.py` — карточка; порядок полей в превью — `Idea.fields()`
- `gsheet.py` — Sheets API: лист идеи (`card_rows`), строка сводки (`index_row`), форматирование

## Как добавить поле
1. Атрибут в `Idea` (`models.py`) + строка в `Idea.fields()` для превью.
2. Метка в `LABELS` (`parser.py`), чтобы её можно было писать в сообщении.
3. Метка в `CARD_FIELDS` и значение в `card_rows()` (`gsheet.py`). Формулы сводки считают номер
   строки по позиции в `CARD_FIELDS`, так что порядок менять можно, но старые листы под новый порядок
   не перестроятся — новые поля лучше добавлять в конец.
